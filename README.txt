GAMAMC — PROPOSTA DE REFORMULAÇÃO VISUAL
=======================================

ARQUIVOS
- index.html: página principal
- styles.css: design responsivo e animações
- script.js: menu mobile e indicador de rolagem

COMO TESTAR
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Teste no computador e no celular.

PUBLICAÇÃO
Se o projeto atual da Vercel for um site estático, substitua os arquivos de
interface pelo conteúdo desta pasta, respeitando a organização do repositório.
Para projetos Node/Next/Vite ou com loja, painel e API, NÃO substitua o projeto
inteiro: integre o visual aos arquivos originais primeiro.
